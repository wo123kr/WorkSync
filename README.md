# WorkSync

## 1. 팀 정보
- **팀명**: WorkSync Team
- **팀원**: 제갈진우

## 2. 프로젝트 소개
- **프로젝트명**: WorkSync
- **한줄 소개**: 전 세계 어디서든, 우리 팀의 '골든 아워'를 찾아주는 초간단 시간 동기화 협업 도구

### 📝 프로젝트 설명
WorkSync는 서로 다른 시간대(Time Zone)에 있는 팀원들이 협업하기 가장 좋은 시간을 즉각적으로 찾아주는 생산성 도구입니다. 복잡한 계산 없이, 직관적인 슬라이더 조작만으로 전 세계 도시의 시간을 한눈에 비교하고 회의 가능한 최적의 시간(Golden/Silver Hour)을 제안합니다.

### 💡 핵심 기능
1. **스마트 타임 매칭 (Golden & Silver Hour)**
   - 팀원 모두가 깨어있는 'Golden Hour' 자동 감지
   - 시차가 너무 큰 경우, 서로 양보 가능한 최선의 시간대 'Silver Hour' 제안 (알고리즘 기반)
2. **직관적인 시각화 (Visual Sync)**
   - 슬라이더 드래그 한 번으로 모든 도시의 시간 변화를 동시에 확인
   - 업무 시간(초록색), 낮(노란색), 밤(회색) 색상 코딩으로 상태 즉시 파악
3. **글로벌 최적화 (Global Ready)**
   - 4개국어 완벽 지원 (한국어, 영어, 일본어, 중국어)
   - 전 세계 주요 도시(23개+) 원클릭 추가 및 자동 현지 시간 변환
4. **개인화 & 생산성 (Productivity)**
   - 별도 로그인 없이 즉시 사용 (LocalStorage 기반 설정 저장)
   - 다크 모드 지원 및 군더더기 없는 미니멀 UI

### 🛠 기술 스택
- **Framework**: Next.js 14 (React), TypeScript
- **Styling**: Tailwind CSS, Shadcn/UI, Framer Motion
- **Deployment**: Vercel / GitHub
