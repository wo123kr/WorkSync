# WorkSync

**시간대가 다른 팀원 모두가 깨어 있는 회의 시간을 바로 찾아 주는 웹 도구.** Trae 해커톤(생산성 도구 부문) 1인 출품작입니다.

**바로 쓰기**: https://work-sync-swart.vercel.app

## 무엇을 하나

서울 오후 3시가 런던 새벽 6시, 뉴욕 새벽 1시라는 걸 매번 검색하고 계산하는 대신, 도시를 고르고 슬라이더를 움직이면 모든 도시의 시각과 상태(업무·낮·밤)가 한 화면에서 같이 움직입니다.

- **Golden Hour** — 모든 도시가 업무 시간인 구간을 자동으로 찾습니다.
- **Silver Hour** — 그런 구간이 없을 만큼 시차가 크면, 서로 가장 덜 양보하는 구간을 제안합니다.
- 고른 시간을 **Google 캘린더 일정**으로 바로 만들고, 도시·시간이 담긴 **공유 링크**를 만듭니다.
- 23개+ 도시, 4개 언어(한·영·일·중), 다크 모드. 로그인 없이 설정은 브라우저에 저장됩니다.

## 핵심 로직

하루를 15분 단위(96칸)로 나눠 칸마다 점수를 매깁니다 — `lib/time-utils.ts`

| 도시의 상태 | 점수 |
|---|---|
| 업무 시간 | +2 |
| 아침·오후·저녁 | +1 |
| 밤 | −2 |

모든 도시가 업무 시간이면 Golden, 아니면 **그날 최고 점수와 같은 칸**을 Silver로 묶어 상위 3개 구간을 보여 줍니다. 밤에 큰 감점을 줘서 "한 사람만 새벽에 일어나는" 시간이 최선으로 뽑히지 않게 했습니다.
